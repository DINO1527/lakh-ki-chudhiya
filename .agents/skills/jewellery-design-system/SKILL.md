# Jewellery Design System

## Before work
Read root AGENTS.md, DESIGN.md and PROJECT_SPEC.md sections 6–7. Inspect current implementation, git status and milestone scope. Use fixture data and authorized environments only.

## Workflow
1. Identify target page, actual assets, layout needs and existing tokens.
2. Identify acceptance criteria and failure scenarios; plan the smallest maintainable change.
3. Use editorial serif/clean sans, maroon/ivory palette with verified contrast; reuse primitives; prioritize mobile product photography, clear CTAs and real content; separate admin visual tone.
4. Add or update focused tests and relevant documentation.

## Verification
Check screenshots at mobile/desktop, keyboard/contrast, loading/empty/error, reduced motion and actual content; no fake ratings.

## Failure handling and completion
If credentials, assets, external tools or runtime compatibility are missing, implement safe local work where possible, label unverified gates and report actual blocker. Do not silently switch architecture, fake success, deploy, provision paid services or operate production. Report changed files, exact checks and remaining risk in docs/PROGRESS.md.
